📊 Available Prometheus Metrics

Metric	Description
ml_predictions_total	Total predictions by status/model
ml_prediction_errors_total	Prediction errors by type
ml_prediction_latency_seconds	Prediction latency histogram
ml_prediction_values	CTAT/VTAT value distribution
ml_model_confidence	Model confidence scores
ml_model_load_status	Model load status (1=loaded)
ml_active_predictions	Active predictions count
ml_cache_hits_total	Cache hit/miss counts
ml_model_performance	MAE, RMSE, R² metrics
